Numerical forecasting connects scientific models, incoming data, and result analysis for time-dependent physical systems. I have worked on reproducible pipelines for data preparation, model execution, output summarization, and anomaly review.

Within this area I work on the following projects:

- **Streaming model workflow.** A time-series data pipeline that prepares model inputs, runs component models, summarizes output, and flags anomalous changes for review.
